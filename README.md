# Personal Portfolio Website
A responsive personal portfolio website built with HTML, CSS, and JavaScript to showcase projects, technical skills, and experience.

## Features
- Responsive layout
- Project filtering
- Skill search
- Time-based greeting/content
- Links to projects and professional information

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- Git and GitHub

# What I Learned
This project helped me practice responsive web design, DOM manipulation, interactive features, and deploying a website with GitHub Pages.
